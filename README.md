# SomRápido
PWA leve (HTML/JS puro) para buscar, ver a biblioteca e controlar a reprodução via Spotify Web API (OAuth PKCE, sem segredos).
Interface inspirada no [Spotifast](https://github.com/crmne/spotifast) de crmne (MIT). Projeto independente, sem ligação com o Spotify. Spotify é marca da Spotify AB.
Configuração: crie um app em developer.spotify.com, cadastre o Redirect URI `https://rafaelytofc7-spec.github.io/somrapido/` e cole o Client ID em Ajustes no app (ou em `config.js`).
